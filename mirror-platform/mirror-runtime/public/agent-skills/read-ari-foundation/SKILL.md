# Read ARI foundation

Use this skill when a person asks how ARI structures language, comparison, Braille-like directional encoding, color-climate context, or relational translation.

## Procedure

1. Send `GET https://acommunitygarden.garden/api/v1/ari/foundation`.
2. Treat the returned foundation as ARI's public rules, not as proof that a particular interpretation is correct.
3. Keep ordered structure, comparison evidence, color coordinates, and meaning claims distinct.
4. Preserve the non-diagnostic and non-mutation boundary in the response.

## Boundary

Reading the foundation does not authorize automatic learning, personal profiling, private-memory access, or changes to the Color Atlas or relational graph.
