Custom GPT Setup

What The GPT Gets

  • Framework rules through getAlignmentReference
  • Single-input color-climate translation through translateColorClimate
  • Selection-set pattern reading through analyzeSelectionClimate
  • Compact approved graph context through findAlignmentContext

The action layer is read-only. It does not expose passwords, private profiles, proposal workflow, or graph administration.

Custom GPT Editor Steps

  1. Open the Custom GPT editor.
  2. In Configure, paste the system instructions from docs/custom-gpt-instructions.md.
  3. Add a new Action.
  4. Choose No authentication.
  5. Import the action schema URL from this page.
  6. Set the privacy policy URL to privacy.html.
  7. Save, then test with one direct phrase and one selection set.

Expected Behavior

  • Explain the supported route before evocative interpretation.
  • Keep mixed climates mixed when more than one route is active.
  • Treat themes as filters and presentation climates, not permanent essence.
  • For selection sets, separate observable pattern from inferred preference.
  • If the route is unresolved, say it is unresolved instead of forcing a color landing.
